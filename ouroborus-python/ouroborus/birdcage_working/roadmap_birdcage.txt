project name:	birdcage 
author:		erik max francis, sat tara singh khalsa
date:		01 nov 2004


**** summary ***

cage is a generic cellular automata engine written in python by erik max francis.
birdcage optimises cage's performance by using the pyrex extension language and 
rewriting the code as needed. Improvements to cage's logic and functionalities
are also welcome.
