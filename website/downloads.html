Downloads!

Like I said, there's very little here at the moment, but that is due more to the webmaster's lack of initiative than to the programmers' want of inspiration, so please don't bear this against them and just be patient while the webmaster gets his act together!

  • The main item in this download site is definitely Project Ouroborus. Get more information concerning dependencies, instalation, running Ouroborus and earlier releases. Download the latest version here.
  • The one and only birdcage library for Python. This can be downloaded as a zip file or a tarball. Birdcage is our Pyrex-optimised Python cellular automaton engine, and includes one ready-to-run demo.
  • Yogiserver. This is a few python files bundled together in a .zip for easy download. Put this on any machine with a reachable IP address and run the server.py file to get an XML-RPC server listening on port 8080. There's a whole bunch of additional instructions that should go with this, but you'll have to wait!
  • Yogiclient. OK. Just so this isn't completely pointless, we have a Yogiserver listening out there in spacemonkey.info, so if you download and execute this simple python script, you'll get a client in your machine in no time. Let us know if it works!
